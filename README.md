# SebbyLogger

by Sebminecrafter

A lightweight utility logger for Java projects

Featuring:

 * Timestamps
 * Colored output
 * INFO/DEBUG/WARN/ERROR messages
 * TRACE messages (Current thread stack trace)

Available on
[Maven Central](https://central.sonatype.com/artifact/io.github.sebminecrafter/sebbylogger)
and
[GitHub Packages](https://github.com/Sebminecrafter/SebbyLogger/packages/3354546)
